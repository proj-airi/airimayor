# Turn-focused recording workspace

Opening an entire long session in a fixed split pane obscured the player's request and counted outer turns together with native agent execution. The offline viewer now opens the latest recorded turn, using recorded turn/origin identities to scope the timeline, event log, metrics, search and playback. Background descendants remain in that scope even when other turns intervene; labels come from recorded player input, without invented task summaries. Whole-session inspection remains available, and recordings without an outer turn open at that scope.

The recording presentation module separates mayor turns from native execution and names control events as session events. It preserves source/epoch/sequence identities, parent links and raw evidence. Changing the stored format or fixing only future producers was rejected because the presentation must explain an existing recording without rewriting it. Inspecting city evidence outside the selected turn temporarily opens the whole session and returns to the original scope and cursor when closed.

Reuse AIRI's pinned `ui-panes` Workbench instead of extending the fixed split layout. The timeline starts at full width; selecting a call opens a resizable inspector on desktop and a tab on narrow screens. Playback remains outside the panels. Metrics show one analysis report, with the original metric cards disclosed separately; distributions use AIRI's aggregation and its minimum sample requirement for p95. Replay projections apply structural records while indexed output chunks remain available at their exact cursor, keeping rewind work proportional to structure rather than streamed text.
